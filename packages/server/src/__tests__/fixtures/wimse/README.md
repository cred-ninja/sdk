# WIMSE example vectors

Non-normative examples from the WIMSE drafts, used by
`identity-wimse.test.ts` as a fixed-clock interoperability check. All values
are public example material; no private key is stored here.

| File | Source |
| --- | --- |
| `s2s-wit.txt`, `s2s-wpt.txt` | `includes/wit.txt` and `includes/wpt.txt` in the WIMSE s2s-protocol drafts repository at commit `499f060` (generated by `examples/main.go` there; WPT `alg` is `Ed25519`). The same WIT is Figure 2 of draft-ietf-wimse-workload-creds-03. |
| `wpt02-fig5-wit.txt`, `wpt02-fig5-wpt.txt` | Figure 5 of draft-ietf-wimse-wpt-02 (RFC 8792 line wrapping removed). This pair uses `alg` `EdDSA` in both `cnf.jwk` and the WPT header. |
| `issuer-bundle.json` | The Identity Server public key from Figure 6 of draft-ietf-wimse-workload-creds-03 (`kid` "June 5"). `"use": "wit-svid"` and `spiffe_sequence` were added here so the key loads as a SPIFFE trust bundle entry; the key members are unchanged. |

Fixed clock used by the tests: `1745509800` (WIT `iat` 1745508910, WIT `exp`
1745512510, WPT `exp` 1745510016). Audience: `https://workload.example.com/path`.
